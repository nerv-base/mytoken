# MyToken 0.5 计划

2026-10-19 与维护者逐项确认。本文件是 0.5 的唯一方向依据；与旧 ROADMAP/SPEC 冲突时以本文件为准。

## 定位

本机 AI 编程工具的**花费与套餐额度看板**。主窗口回答“今天/这个月花了多少、额度还剩多少”；托盘回答“现在正在烧多少”。年度热力图等回顾类内容放在次要位置。

不做：中转站对账、供应商倍率与折扣、预算与提醒、多实例、缓存账本。

## 口径

- **花费 = 官方 API 价格**，界面统一标注“API 等价”。不做任何折扣或倍率。
- 没有官方价格的模型显示“未定价”，不按 $0 计入；用户可在设置里给未知模型补价。
- **token 主数字不含缓存读取**。展示时拆成输入 / 输出 / 缓存读取 / 缓存写入。
- **缓存命中率只有一个公式**：`cache_read / (input + cache_read + cache_write)`。
- 缓存写入区分 5 分钟和 1 小时两档；1 小时按 2 倍输入价计价，5 分钟按 1.25 倍。

1. Claude Desktop 的 Code 标签页 ledger（surface="code"）与 claude-code 的 `~/.claude/projects` 重复计数（本机多算约 $40.5）。对应关系见 `Claude-3p/claude-code-sessions/**/local_*.json` 里的 `cliSessionId`。
2. Cowork ledger 按“轮”汇总，去重却按单次请求比对（`internal/harness/claudedesktop/claudedesktop.go:597-623`），导致重复计数。
3. `cache_creation.ephemeral_1h_input_tokens` 没有解析，1 小时缓存写入按 5 分钟价格计。
4. ledger 去重键只精确到秒（claudedesktop.go:848、866）。
5. Windows 托盘必须左键才能退出；应支持右键弹出菜单并退出。

## 数据来源（harness）

- 继续扩充，尽量覆盖更多工具。
- 全部编译进程序，实现统一接口；每个 harness 在设置里有开关。
- 自动检测安装目录。没检测到但确实装了的，用户可以手动选目录，选完立即校验并提示能不能用。
- 状态展示：已检测 / 未检测 / 已禁用 / 目录无效，以及事件数和最近一次读到数据的时间。

## 套餐额度

- 额度一律联网从服务商服务器获取（例如 Codex 的 ChatGPT backend usage 接口），本地日志只用来算 token 与花费；本地缓存的只是服务器上次返回的快照。
- Claude、Cursor 等需要联网的，检测到本机已登录的凭据就自动联网查询，不单独征求同意。
- 没检测到套餐的工具不显示额度卡片。

## 界面

- 保留数据层（store/query/harness/pricing/quota），重写 `internal/gui`；升级 MyGo 到 v0.5.5。
- 视觉：不透明底色，干净克制。动效只放在几处：额度环弹簧回弹 + 锥形渐变、金额数字滚动、切换时间范围时图表平滑变形、托盘磨砂玻璃 + 随消耗速度流动的光带。
- 性能约束：玻璃材质只在托盘面板用一块；动画只用不触发视图重建的方式（Pose / ContentTransition / Draw 内用 `p.Now()`）；悬停命中检测放在 Draw 里；派生数据缓存在状态层，不在视图函数里算。
- 导航 5 页：
  - **概览**：今日花费（大字，标“API 等价”）+ 本月花费 + 按当前速度估算的月底花费 → 检测到的额度环 → 按天花费柱状图（7/30/90 天，按工具堆叠）→ 按工具、按模型的花费占比，以及缓存命中率。
  - **会话**：虚拟化列表，可按花费或时间排序、按工具筛选、搜索；详情显示逐次请求、模型、命中率、花费曲线。
  - **排行**：按花费排序，维度可切换为工具 / 模型 / 供应商；年度热力图、连续天数等回顾内容也放在这一页。
  - **项目**：按仓库或目录汇总；详情显示每日花费和会话列表（虚拟化）。
  - **设置**：左侧分组侧栏，共 4 组：通用（语言、主题、时区、货币、开机启动、菜单栏显示内容）/ 数据来源 / 价格（只读的官方价格表 + 未定价模型补价）/ 数据维护（重新扫描、数据库位置与大小、导出、关于）。所有修改即时生效；失败必须有提示；删除要确认。
- 托盘：
  - 菜单栏文字默认显示今日花费，可在设置里自选今日花费 / 当前 TPS / 命中率 / 额度百分比中的任意几项。
  - 点开是弹出面板，显示今日花费、本月花费、各套餐额度条（带重置倒计时），以及正在进行的会话。每个会话显示输出 TPS（没有耗时信息的工具按请求间隔估算，标“约”）、命中率和每小时花费。
  - Windows 上右键弹出菜单，可以直接退出。

## 性能硬指标（在维护者真实数据副本上实测，约 25.5 万事件）

| 指标 | 0.4.x 实测 | 0.5 目标 |
|---|---|---|
| 全新全量扫描 | 22 分 58 秒 | ≤ 15 秒 |
| 增量扫描 | 约 131 ms | ≤ 25 ms |
| 空闲时后台 CPU | 约 59% 单核 | < 0.5% |
| 文件句柄 | 5433 | < 150 |
| 界面刷新一次 | 约 636 ms | < 25 ms |
| 切页 / 悬停 / 滚动时单帧（`MYGO_FRAME_STATS=1`） | — | ≤ 8 ms |
| CLI 只读命令 | 0.4 s 以上 | < 150 ms |
